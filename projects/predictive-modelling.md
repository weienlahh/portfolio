# Predictive Modelling & Statistical Analysis

**Technologies:** R, Statistical Modelling, Regression, Decision Trees

## Overview

Applied statistical modelling and machine learning techniques to automotive and healthcare datasets, with a focus on model interpretation, predictive performance, uncertainty, and generalisation.

## Key Work

- Built multiple linear regression models to analyse factors affecting vehicle fuel efficiency.
- Applied significance testing and Bonferroni correction to identify meaningful predictors.
- Developed logistic regression and decision-tree models for heart-disease classification.
- Used cross-validation to select and compare models.
- Evaluated predictive performance using ROC-AUC, classification accuracy, and log-loss.
- Applied bootstrap confidence intervals to quantify uncertainty.
- Analysed model complexity using the bias-variance trade-off and investigated overfitting.

## Example Result

In one heart-disease classification task, the selected logistic regression model achieved an ROC-AUC of **0.88** and classification accuracy of **83%**, outperforming the evaluated decision-tree model on those metrics.

## Skills Demonstrated

R, Statistical Modelling, Regression, Classification, Cross-Validation, Model Evaluation, Bootstrapping, Hypothesis Testing, Data Interpretation
