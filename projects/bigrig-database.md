# BigRig Movers Data Management System

**Technologies:** Oracle SQL, MongoDB, Relational Databases

## Overview

Designed and implemented a database system for a logistics business managing customers, employees, trucks, trailers, quotations, and transport jobs.

## Key Work

- Implemented relational tables from a logical database model.
- Defined primary keys, foreign keys, unique constraints, and business validation rules.
- Created realistic test datasets and performed transactional data manipulation.
- Modified the database schema to support additional business requirements.
- Developed analytical SQL queries using joins, aggregation, subqueries, formatting, and conditional logic.
- Generated nested JSON structures from relational data.
- Queried transformed data using MongoDB.

## Example Analysis

Developed SQL queries to analyse:

- customer quotation activity and average quoted costs;
- employee scheduling activity;
- vehicle utilisation;
- truck and trailer combinations relative to average fleet usage.

Received **90/100** for the completed database assignment, including strong results in SQL querying and MongoDB components.
